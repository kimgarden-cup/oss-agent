# week9 도구 함수 정리

## 개요

- 실제로 읽은 파일은 `week9/tools.py.py`임용용체.
- 영화진흥위원회(KOBIS) 오픈 API에서 일별 박스오피스 정보를 조회하는 함수 두 개가 있음용용체.
- API 키는 `secret.py`의 `API_KEY`에서 가져오며, 요청에는 10초 타임아웃을 설정함용용체.

## 함수 목록

### `get_boxoffice_rank_1(date)`

- 지정한 날짜의 박스오피스 1위 영화 제목을 반환함용용체.
- `date`는 `"20260824"`와 같은 8자리 날짜 문자열임용용체.
- API에 날짜를 전달해 일별 박스오피스 목록을 가져온 뒤, 첫 번째 영화의 `movieNm` 값을 반환함용용체.
- 목록이 비어 있거나 응답 데이터 형식이 다르면 예외가 발생할 수 있음용용체.

### `get_movie_audience(date, title)`

- 지정한 날짜의 박스오피스 목록에서 제목이 일치하는 영화의 관객 수를 찾아 반환함용용체.
- `date`는 8자리 날짜 문자열이고, `title`은 찾을 영화의 제목임용용체.
- 제목은 목록의 `movieNm`과 완전히 일치해야 함용용체.
- 영화를 찾으면 `audiCnt`를 정수로 바꾼 뒤 천 단위 쉼표와 `명`을 붙여 반환함용용체.
- 해당 날짜 목록에 영화가 없으면 `'<영화 제목>'은(는) <날짜> 순위에 없습니다.` 형식의 안내 문장을 반환함용용체.

## 공통 동작

- 두 함수 모두 `BASE_URL`에 `key`와 `targetDt` 쿼리 파라미터를 붙여 GET 요청을 보냄용용체.
- 응답 JSON의 `boxOfficeResult.dailyBoxOfficeList`에서 영화 정보를 읽음용용체.
